# Packaging & distribution (Phase 150)

The forge CLI ships through four channels:

| Channel | Source of truth | Install |
|---|---|---|
| npm | `packages/cli` (bundled `dist/forge.js`, requires Bun) | `bun install -g forge` / `npm i -g forge` |
| Homebrew | `packaging/homebrew/forge.rb` (standalone binary) | `brew install --formula ./packaging/homebrew/forge.rb` |
| Scoop | `packaging/scoop/forge.json` (standalone binary) | `scoop install forge` (from a bucket) |
| WinGet | `packaging/winget/` (portable Windows zip) | `winget install Inbesat.Forge` |

The standalone binaries are built by `scripts/build-binary.ts` (Phase 149) and
attached to every `v*` GitHub release together with `checksums.txt`
(sha256 per asset, generated by the release workflow).

## Release checklist (human steps)

1. Tag a release (`git tag v0.1.0 && git push origin v0.1.0`). The release
   workflow builds all five binaries, zips the Windows one for WinGet, and
   publishes `checksums.txt`.
2. npm: `cd packages/cli && npm publish` (login first). The registry name
   `forge` must be free — as of 2026-10 it resolves to an unrelated package
   (v2.3.0), so a scoped name such as `@inbesat/forge` will likely be required;
   renaming means updating `packages/cli/package.json` plus
   `DEFAULT_PACKAGE_NAME` in `packages/core/src/update/index.ts`.
3. Homebrew: update `version` and the four `sha256` values in
   `packaging/homebrew/forge.rb` from `checksums.txt`, then copy the file into
   a tap repo (`homebrew-<name>`) as `Formula/forge.rb`.
4. Scoop: copy `packaging/scoop/forge.json` into a bucket repo's `bucket/`
   directory. `checkver`/`autoupdate` pick up future releases and read hashes
   from `checksums.txt` automatically.
5. WinGet: fill `InstallerSha256` from `checksums.txt` and submit the three
   `packaging/winget/*` files to microsoft/winget-pkgs under
   `manifests/i/Inbesat/Forge/<version>/`.

Version bumps keep `packages/cli/package.json` (and `VERSION` in
`packages/core`) in sync with the manifests; `bun test scripts` asserts this.
